    Qt TcpChat — 基于 Qt TCP 的网络即时通讯与文件管理系统
================================================================================

【项目简介】

这是一个 C++/Qt5 框架开发的双端程序，包含 Client（客户端）和 Server（服务端）。

客户端提供图形界面供用户登录、注册、添加好友、一对一聊天；集成文件管理模块，
支持创建/删除/重命名文件夹和文件。

服务端基于 TCP 监听客户端连接，通过 MySQL 数据库管理用户信息和好友关系，负责
消息转发与在线状态维护。

两端通过自定义二进制协议 PDU（Protocol Data Unit）交互，采用单例模式管理核心类，
是典型的 Qt 网络编程 + 数据库综合项目。

【实操过程】
================================================================================

一、环境准备

    Qt 5.x + MySQL 5.7+ + C++11 编译器 (MinGW / MSVC)

二、数据库建表

    启动 MySQL，执行以下 SQL：

    CREATE DATABASE test;
    USE test;

    CREATE TABLE user_info (
        id INT AUTO_INCREMENT PRIMARY KEY,
        name VARCHAR(32) NOT NULL UNIQUE,
        pwd  VARCHAR(32) NOT NULL,
        online TINYINT DEFAULT 0
    );

    CREATE TABLE friend (
        id INT AUTO_INCREMENT PRIMARY KEY,
        user_id INT NOT NULL,
        friend_id INT NOT NULL
    );

三、配置 client.config

    Client 和 Server 目录下的 client.config 内容格式（通过 .qrc 编译进程序）：

        127.0.0.1
        8888
        D:/Qt/2503/ServerData

    第 1 行 = 服务器 IP 地址
    第 2 行 = 端口号
    第 3 行 = 用户文件存储根目录（服务端会在该路径下为每个用户创建文件夹）

四、编译

    # 服务端
    cd D:/Qt/2503/Server
    qmake Server.pro
    make

    # 客户端
    cd D:/Qt/2503/Client
    qmake Client.pro
    make

    注意：Client 的 main.cpp 有 Git 合并冲突需要先手动解决！

五、运行

    1. 确保 MySQL 已启动
    2. 先启动 Server -> 自动连接数据库并监听端口
    3. 再启动 Client -> 注册账号 -> 登录 -> 添加好友 -> 开始聊天
    4. 文件管理功能可创建/浏览文件夹、删除/重命名文件

六、关键数据流（用户登录为例）
